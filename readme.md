Portfolio de Micaela Suárez

Descripción del proyecto:
Este proyecto consiste en el desarrollo de un portfolio web personal realizado para la materia Computación 3 de la Licenciatura en Diseño y Comunicación Visual de la Universidad Nacional de Lanús (UNLa).

El sitio presenta mi identidad como diseñadora, una breve descripción de mi perfil profesional y un espacio de contacto.

Tecnologías utilizadas:
HTML5: estructura y contenido del sitio.
CSS: Estilos, colores, tipografias y distribucion de elementos.
Figma: diseño y prototipado de la interfaz.
Visual Studio Code: editor utilizado para desarrollar el sitio.

Tipografías
Fredoka: utilizada en títulos principales.
Montserrat: utilizada en textos, navegación y botones.
Las tipografías se incorporaron mediante Google Fonts.

Estructura del sitio
index.html: página de inicio y presentación personal.
contacto.html: página con formulario de contacto.
estilo.css: hoja de estilos compartida.
img/: recursos gráficos e imágenes.
audio/: archivo de audio utilizado en el sitio.

Resolución de trabajo
El diseño de escritorio se desarrolló tomando como referencia una resolución de 1920 × 1080 px.
